# Internship Project Repository

Welcome to the repository of my internship project. This space contains all the research and development work focused on Reinforcement Learning.

## Repository Structure

- **`QLearning/` - Complete framework:** This is the main and complete directory of the project. It contains the final implementation of the Q-Learning algorithm, enhanced with contextual reward/punishment rules and various replay architectures.
  *[Read the detailed QLearning project README](./QLearning/README.md)*

- **Other directories:** The remaining folders in this repository (outside of `QLearning`) contain tests, preliminary trials, and study scripts created during the exploratory phases of the internship.
